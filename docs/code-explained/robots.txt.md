# `robots.txt`

**HECHO VERIFICADO:** el archivo contiene dos directivas para crawlers:

| Directiva | Valor | Efecto declarado |
|---|---|---|
| `User-agent` | `*` | aplica el bloque a todos los agentes que respetan robots.txt |
| `Allow` | `/` | permite rastrear desde la raíz |
| `Sitemap` | `https://setupoficina.com.ar/sitemap.xml` | anuncia la URL absoluta del sitemap |

No hay reglas `Disallow` versionadas.

**INFORMACIÓN NO IDENTIFICADA:** el archivo expresa instrucciones públicas; no puede demostrar que un crawler concreto las respete ni que la URL esté publicada actualmente.
