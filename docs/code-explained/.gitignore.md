# `.gitignore`

**HECHO VERIFICADO:** estas reglas determinan qué archivos locales no propone Git para versionar. No borran archivos ni afectan por sí mismas al runtime.

## Trabajo local y backups

| Patrón | Excluye |
|---|---|
| `_entrada-local/` | carpeta local con ese nombre |
| `*_backup*/` | directorios cuyo nombre contiene `_backup` |
| `*.rar`, `*.zip` | archivos comprimidos RAR/ZIP; incluye el ZIP local encontrado en `assets/images/` |

## Secretos y configuración local

| Patrón | Efecto |
|---|---|
| `.env`, `.env.*` | excluye archivos de variables de entorno |
| `!.env.example` | vuelve a incluir la plantilla pública versionada |
| `.dev.vars`, `.dev.vars.*` | excluye variables locales de desarrollo |
| `wrangler.toml.local` | excluye una configuración Wrangler local con ese nombre |

## Dependencias, cachés y builds

| Patrón | Efecto |
|---|---|
| `node_modules/` | dependencias npm instaladas |
| `.wrangler/`, `.cache/`, `coverage/`, `dist/`, `build/` | cachés, cobertura y salidas generadas |
| `!tiendanube-script/build/` | vuelve a admitir ese directorio concreto |
| `tiendanube-script/build/*` | excluye su contenido por defecto |
| `!tiendanube-script/build/backend-url.mjs` | conserva como fuente la validación de URL de backend |

## Logs y archivos de herramientas

Excluye `*.log`, logs de npm/yarn, `.DS_Store`, `Thumbs.db`, `.vscode/` e `.idea/`.

## Temporales específicos del proyecto

| Patrón | Efecto comprobado |
|---|---|
| `/assets/setup-layers/import/*.png` | mantiene fuera de Git entradas PNG temporales de importación |
| `/artifacts/` | salidas locales genéricas |
| `/db/generated/` | SQL/datos generados localmente |
| `/_worker.bundle` | bundle local de Functions |
| `/tests/visual-output/` | composiciones/reportes visuales locales |

**HECHO VERIFICADO:** durante la auditoría las reglas alcanzaban `tiendanube-script/node_modules/`, `.wrangler/`, `_worker.bundle`, `tests/visual-output/` y `assets/images/Escritorio.zip`.
